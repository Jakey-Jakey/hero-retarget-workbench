Boundaries

The handoff holds.

These are project rules. The failures behind each one are recorded in the tickets and the ledger.

vmdl input

No KV3 parser, no reconstruction, no metadata extraction. The source file reaches the compiler with its bytes unchanged.

CSDK13 compiler

A compile claim starts with `resourcecompiler` returning zero. The temporary build mirror is removed in `finally`.

unmatched groups

Choose a target, mark it extra, or ignore it. The addon does not infer a nearest bone.

proof gate

A stale, unchecked, or refused Axis proof stops the export. The status line names the check that failed.

Install

Build the addon zip.

The builder reads the version from bl_info and writes a self-contained zip under dist/. The installed addon carries its own forge/ core and the vendored BLAKE3 extension.

Install it in Blender 5.4 from Preferences → Add-ons → Install from Disk. Enable PulseSrcOps before the workbench.

build / checkout 
python tools/build_addon.py
# dist/deadlock_model_forge-0.2.2.zip
python tools/project.py doctor
python tools/project.py selftest

# the compile gate needs the CSDK13 path
python tools/project.py compile --help

Blender5.4 with PulseSrcOps for DMX import and export. SourceIO is needed for compiled Source 2 assets.

SourceDeadlock on Steam and the Source 2 Viewer CLI. The live build is read from the install at run time.

CompilerA reduced CSDK13 install with resourcecompiler.exe. The addon never uses CSDK hero files as model source.
